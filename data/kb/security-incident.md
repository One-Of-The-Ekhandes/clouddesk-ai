---
title: Suspicious sign-in, phishing or compromised account
category: security
team: security_team
---
Symptoms: suspicious sign-in alert, user clicked a phishing link, unknown MFA prompts, mailbox rules the user did not create.

Steps:
1. Treat as urgent. Do not ask the user to forward the phishing email to colleagues.
2. Reset the password, revoke sessions and check MFA enrolment.
3. Escalate to the security team immediately with the alert details.
Possible security incidents are always escalated.
