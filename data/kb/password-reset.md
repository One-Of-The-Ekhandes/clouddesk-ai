---
title: Password expired or forgotten
category: account_access
team: service_desk
---
Symptoms: "your password has expired", forgotten password, user travelling without access to the office network.

Steps:
1. Point the user to self-service password reset (SSPR) first.
2. If SSPR is not registered, verify identity and issue a temporary password that must be changed at next sign-in.
3. Remind the user to update the password on phones and saved credentials to avoid a lockout.
